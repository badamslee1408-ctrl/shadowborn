# Shadowborn

Offline stencil maker. Upload an image (or snap one), tune it with live controls, and export cut-ready stencils.

- Threshold + edge-detect modes, brightness/contrast/blur controls
- Auto-bridges so cut pieces hold together
- Multi-layer mode for multi-color stencils
- Export PNG, SVG, or print-ready sheet

**Privacy:** everything runs on-device. No uploads, no analytics, no network calls — any image stays on your device.

**Android app:** grab the APK from [Releases](../../releases).
